# 2026-09-18：Gradient norm 与轮内 KL 回顾分析结果

## 范围与数据

本实验仅完成已确认计划中的第 1–3 项：①单步 gradient norm 与 adjacent KL，
②累计 KL 的非加性与有效残差，③只使用第 4 步已知信息的未来峰值预测。第 4 项的新
GPU 测量与策略对照不在本实验范围内。

输入是 [原 N=4/N=8 实验](../../20260909_full_kl_no_warmup_n4_n8/README.md)
的 `kl_updates.jsonl`，在本实验 `raw/n4/` 和 `raw/n8/` 中归档逐字节副本。N=4
有 24 轮、96 次更新；N=8 有 24 轮、192 次更新；两组均为 seed 1、固定学习率
`1e-6`。每轮测量使用自己的 anchor 和固定前缀，轮间更换前缀。因此同轮可以研究
KL 累积，跨轮不能把曲线接成同一个 KL 基准。运行脚本
[`scripts/analyze.py`](../scripts/analyze.py)先断言逐更新编号、age、anchor、轮内
前缀标识、KL 方向与正值等基本口径。

本实验不使用模型参数或 Fisher 矩阵。令 `d_{t,a}` 为相邻全词表 KL，`K_t(a)` 为
相对本轮 anchor 的累计全词表 KL，`G_{t,a}` 为日志中的更新前 gradient norm。

## 1. 单步 gradient norm → adjacent KL

用 N=4 的全部 24 轮 age 1–4 拟合三种基线：常数 `d`、固定系数的
`d_hat = c (eta G)^2`，以及自由指数的 `log d_hat = b0 + beta log G`。其中 `c`
取训练样本 `d/(eta G)^2` 的中位数；自由指数用最小二乘拟合。模型完全冻结后，
分别检验 N=8 的 age 1–4 和使用**已观测未来梯度**的 age 5–8。后者仅是
oracle-gradient 回顾性检验，不能用于第 4 步的在线决策。

误差主指标是 `median exp(|log(d_hat/d)|)`：1 表示准确，1.20 表示典型乘性偏差
约 20%。同时记录平均绝对对数误差、偏差和训练残差第 90 百分位形成的诊断性上界。
该上界是训练内残差得到的，**不是校准后的置信上界**。

| 检验样本 | 常数模型典型误差因子 | 固定二次模型 | 自由指数模型 |
| --- | ---: | ---: | ---: |
| N=8 age 1–4，96 次更新 | 1.267 | 1.173 | 1.187 |
| N=8 age 5–8，96 次更新；已观测未来梯度 | 1.228 | 1.198 | 1.168 |
| N=8 前 96 次更新中的 age 1–4，48 个点 | 1.303 | 1.170 | 1.151 |
| N=8 前 96 次更新中的 age 5–8，48 个点；oracle | 1.267 | 1.199 | 1.136 |

N=4 的 `c_eff=d/(eta G)^2` 中位数为 `1.481×10^11`；N=8 age 1–4 和
age 5–8 分别为 `1.401×10^11`、`1.423×10^11`。按 age 的中位数与四分位数
见 [`coefficient_by_age.csv`](../tables/coefficient_by_age.csv)。自由指数在 N=4
拟合的 `beta=1.189`；按连续四轮为块的自助重采样，描述性 95% 区间为
`[0.039, 1.563]`。该区间只反映此单次轨迹内部的重采样，不是跨独立运行的置信区间。

结论限于：当前日志中，梯度范数包含预测相邻 KL 的信息，固定二次换算是有用的
经验近似，但系数并非严格常数。`beta` 不等于 2 不能否定参数位移的局部 Fisher
二次展开：AdamW 的实际位移不等于 `-eta g`，而且当前学习率固定，无法单独检验
学习率平方律。逐更新数值见 [`local_conversion.csv`](../tables/local_conversion.csv)。

## 2. 累计 KL 的非加性

逐更新计算

```text
C_{t,a} = K_t(a) - K_t(a-1) - d_{t,a},  a >= 2
rho_eff_{t,a} = C_{t,a} / [2 sqrt(K_t(a-1) d_{t,a})]
```

这两个量按定义可计算；检验的是其经验大小、符号与直接求和近似的误差，**不是**
把定义恒等式当作理论证明。结果：N=4 的 72 个非首步、N=8 的 168 个非首步，
`C` 全部为负；两组都没有 `|rho_eff|>1` 的记录。各 age 的 `rho_eff` 中位数约在
`-0.44` 至 `-0.49` 之间。N=4 终点 `K_t(4)/sum_{a<=4}d_{t,a}` 的轮间中位数
为 0.289，N=8 终点对应比值为 0.152。换句话说，直接相加相邻 KL 在这些终点
上分别产生约 3.46 倍和 6.56 倍的中位乘性误差。轮内累计 KL 也不是逐步单调的：
N=4 有 21/72 个非首步下降，N=8 有 73/168 个非首步下降。

这些是强烈的**非加性证据**，但负的 `rho_eff` 不能直接解释为真实更新向量在同一个
Fisher 度量下负对齐：相邻 `d` 与 anchor 累计 `K` 的展开点不同，且高阶误差未知。
逐点结果见 [`cumulative_residuals.csv`](../tables/cumulative_residuals.csv)，
按 age 汇总见 [`accumulation_by_age.csv`](../tables/accumulation_by_age.csv)。

## 3. 第四步预测未来累计 KL 峰值

仅在 N=8 的每轮第 4 次更新结束后构造特征：起始真实更新编号、前四步累计 KL
峰值 `E_t=max_{a<=4}K_t(a)`、前四步 gradient norm 均值。预测目标为
`T_t=max_{5<=a<=8}K_t(a)`。按时间顺序用前 16 轮拟合固定正则强度 1 的岭回归，
最后 8 轮留出；依次比较“仅训练进度”“再加早期 KL”“再加早期梯度”。另列
不拟合的 `T_hat=E_t` 基线。没有使用 age 5–8 的梯度、KL 或评测输入作特征。

| 预测方式 | 留出 8 轮平均绝对对数误差 | 典型误差因子 | 低估轮数 |
| --- | ---: | ---: | ---: |
| 仅训练进度 | 0.597 | 1.740 | 8/8 |
| + 前四步 KL 峰值 | 0.406 | 1.413 | 8/8 |
| + 前四步 gradient norm 均值 | 0.310 | 1.321 | 8/8 |
| 直接用前四步峰值 `E_t` | 0.138 | 1.140 | 6/8 |

三个拟合模型加入信息后误差依次降低，但在较晚的留出阶段**全部低估**。
它们用训练残差第 90 百分位得到的诊断性上界，在留出 8 轮中的覆盖数也均为 0/8。
直接用早期峰值虽然误差更低，仍在 6/8 轮低估；全部 24 轮中有 18 轮的未来峰值
高于早期峰值。这说明早期信息有信号，但现有拟合不能成为安全的 KL 预算规则。
逐轮输入、预测及上界见 [`future_peak_predictions.csv`](../tables/future_peak_predictions.csv)。

## 解释边界与复现

- 两组各只有一次 seed 1 运行；第 3 项只有 24 个 N=8 窗口、8 个留出窗口，不能
  验证跨运行泛化或可靠的高分位覆盖率。训练阶段与轮间前缀分布同时变化。
- 当前日志没有实际参数更新向量或 `update_norm`，因此没有计算理想 Fisher cosine，
  也没有直接验证局部 Fisher 二次近似。
- 尚未确定 KL 预算 `delta`，也未用能力、ratio、ESS 校准；本实验不报告“安全 N”
  或动态 controller 的效果。
- 本实验没有新 GPU 作业。所有派生数据由
  `python experiments/20260918_gradient_kl_validation/scripts/analyze.py` 从本目录
  `raw/` 只读生成到 `tables/`；完整数值在 [`summary.json`](../tables/summary.json)。
